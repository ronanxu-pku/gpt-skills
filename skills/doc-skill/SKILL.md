## 默认文档

项目默认设置两个文档：
- README.md
- Implementation.md

默认放在当前代码工作树根目录。
对 gpt-skills 这类独立仓库，放在仓库根目录。

初始化时，在文档确切位置已获授权的前提下，
可以创建缺失的空文件。
不得覆盖已有文件，也不得自动加入标题、模板或占位正文。

未确定位置时，先提出这两个文件的具体路径并询问，
不自行在所有工作树批量创建文档。

## README.md

由用户描述项目已经完成、可以实际使用的功能及使用方法。

可以包含：
- 已实现功能。
- 使用前提和必要配置。
- 已验证的运行命令。
- 输入、输出及已知限制。

未实现的设计不能写成现有功能，
未经验证的命令不能写成已验证用法。

## Implementation.md

由用户描述项目构建方案、实施计划和完成情况。

可以包含：
- 目标和范围。
- 结构与实现方案。
- 分阶段任务及验收条件。
- 当前完成情况、未完成项和计划调整。

计划不等于执行授权，任务被写进文档也不等于获准修改文件、
创建环境、下载数据或执行实验。

## agent 权限

README.md 和 Implementation.md 的正文由用户亲自撰写和维护。
agent 只有查看和提案权。

agent 可以在对话中：
- 指出文档与代码或验证结果不一致的位置。
- 提出新增、删除或替换文字的建议。
- 给出供用户采用的完整候选段落。
- 根据实际工作提出完成情况更新建议。

agent 不得直接编辑、追加、格式化或自动更新这两个文档，
也不得把“同步完成情况”理解为自行修改 Implementation.md。

每个阶段结束时，对照实际结果提出状态更新建议，
由用户将修改写入文档。
用户认可某个建议，不自动代表改变上述正文编辑权限。

不得通过另建其他说明文档或自动生成文件绕过本规则。

共享规则与项目独有规则的冲突、修改及更新方式，遵守
[skill-update-skill](../skill-update-skill/SKILL.md)。
